Verification

Cryptographic integrity records for The AI-Blockchain Symbiosis / A Simbiose IA-Blockchain.

This page hosts the cryptographic proofs of integrity and anteriority for both editions of the book. The base version of each paperback was hashed with SHA-256 and anchored on the Bitcoin blockchain via the OpenTimestamps protocol. The page offers what is needed to verify the proof — not a copy of the book itself.

A página oferece o necessário para verificar a prova — não uma cópia do próprio livro.
